Тесты

Юнит-тесты (16 штук)
- Начальное состояние `AnimeViewModel` — `Initial`
- Успешная загрузка списка — `Success`
- Ошибка загрузки — `Error`
- Retry после ошибки инициирует новый запрос
- Пустой результат → `Empty`, не `Success`
- Сброс в `Initial` при пустом запросе
- Отмена старого запроса при новом вводе (нетривиальный)
- Retry реально вызывает repository повторно (нетривиальный)
- Начальное состояние `AnimeDetailsViewModel` — `Initial`
- Успешная загрузка деталей — `Success`
- Ошибка загрузки деталей — `Error`
- Повторный `loadAnime` с тем же id не делает лишний запрос (нетривиальный)
- `isFavourite` возвращает корректное значение из Flow
- `toggleFavourite` добавляет если не в избранном
- `toggleFavourite` удаляет если уже в избранном

Интеграционные тесты (6 штук, Room)
- Вставка и чтение из БД
- Удаление из БД
- Дубли не создаются (REPLACE стратегия) (нетривиальный)
- Сортировка по алфавиту работает корректно
- `isFavourite` возвращает `true` после вставки
- `isFavourite` возвращает `false` после удаления

Flow тесты
- `isFavourite` возвращает корректное значение из Flow
- Отмена устаревшего запроса при новом вводе
